How this page works

Here you manage the pieces shown in the shop. Changes are live for everyone within 1 to 2 minutes. Open a topic below for the steps.

What is this page?

This is the shop admin. Only you use it; visitors never see it. From here you can add pieces, edit them, mark them sold out and remove them.

Name, price and description appear on the site exactly as you type them. Prices are in US dollars. Every piece gets its own Add to cart button and a WhatsApp button; a customer who presses it writes to you about that piece.

Set up this phone (do this once)
  1. Open this page in the phone browser (Chrome or Safari), not inside another app.
  2. Log in with your username and password.
  3. Paste the publish key in the box at the bottom of the page and press Save key. You get the key from the person who looks after the site, or you create it yourself (see "How to create the key on a phone").
  4. On an iPhone, add this page to the Home Screen (Share, then Add to Home Screen) and open it from there. Safari forgets site data after a week without a visit; the Home Screen app does not.
  5. Keep a copy of the key somewhere safe (a password manager). If the page ever says "No key on this device yet", paste it again.
How to add a piece
  1. In "Add a piece", type the name (for example Rope chain, 14K, 50 cm).
  2. Choose the category: Gold, Silver or Watches.
  3. For gold and silver choose the type (rings, chains, bars and coins...) and the purity (18K, 925...). For watches type the brand.
  4. Type the weight in grams and the size if there is one (ring size, length in cm, case in mm).
  5. Type the price in US dollars, digits only. If the piece is on sale, type the old price in Original price; the shop shows a Sale badge and the old price crossed out.
  6. Add a short description (optional): material, finish, what is included.
  7. Choose up to 4 photos from the gallery. The first one is the cover. Photos are shrunk automatically, you do not need to prepare them.
  8. Leave In stock ticked. Tick Show on the home page for a piece you want in the featured row. Pick a badge if you want one.
  9. Press "Add and publish" and wait for the green message.
  10. After 1 to 2 minutes the piece is in the shop.
How to edit a piece
  1. In the list "Pieces in the shop" press "Edit" next to the piece. The form fills with its details.
  2. Change whatever you need. The web address of the piece stays the same.
  3. Photos: the current photos are shown with a Remove button each. Add new ones only if you want more or different ones.
  4. Press "Save changes" (or "Cancel" to leave without saving).
Sold out and removing

"Mark sold out" keeps the piece visible in the shop with a Sold out badge and no Add to cart button. Press "Back in stock" when it is available again.

"Remove" deletes the piece from the shop after a confirmation. If you need it again later, add it again. Photos are never deleted from the site, so nothing else breaks.

There is no quantity. A piece is either in stock or sold out.

Photos

Up to 4 photos per piece, JPG or PNG, straight from the phone gallery. They are resized to 1200 pixels on the long side before upload, so even large photos are fine. The first photo is the cover shown in the shop list; use "Make cover" to change it.

Square photos on a plain light background look best in the shop.

Why the publish key is needed

The site is stored on GitHub, and GitHub needs a key to allow changes. Without it you can log in and see the list, but you cannot publish.

The key is set once per device (phone, computer) and stored only on that device, encrypted with your password, not on the site. It expires after about a year; then you create a new one.

How to create the key on a phone

Important: do this in the phone browser (Chrome or Safari), not in the GitHub app. The app does not have this setting.

  1. Open the page to create a key and log in to the GitHub account that owns the site. If it asks to open the GitHub app, stay in the browser.
  2. Give it a name (for example DiOro admin phone) and the longest expiry offered.
  3. Under Repository access choose Only select repositories and pick dioro999.
  4. Under Permissions, Repository permissions, Contents set Read and write. Careful: Read and write, not only Read. Without it publishing fails.
  5. Press Generate token and copy the key (it is shown only once).
  6. Come back to this page, paste it in the box "Publish key" below and press Save key.
Common problems
  • "GitHub did not accept the key": the key is mistyped or has expired. Create a new one.
  • "The key cannot see the site's repository": create it again with Only select repositories and pick dioro999.
  • "The key cannot write to the site": create it again with Contents: Read and write.
  • "Save the publish key first": this device has no key yet. Paste it once and it does not ask again.
  • "No key on this device yet" after it used to work: the browser cleared its data (Safari does this after a week without a visit). Paste the key again, and open the page from the Home Screen next time.
  • "This photo could not be read": try another photo (JPG or PNG).
  • "Someone else published at the same time": two devices saved at once. Press the button again.
  • The change is not showing yet: wait 1 to 2 minutes and refresh the shop page.
  • Forgot the password? Ask the person who looks after the site.
